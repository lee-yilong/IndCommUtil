# 0019. 工作台 UI 重构：自绘标签栏与会话内工具栏

- **状态**：已接受（实现已按本文修订）
- **日期**：2026-10-30
- **修订**：2026-10-31，按实际落地实现更新
- **决策者**：项目所有者

## 背景

随着 `IndComm` 功能日益丰富（多协议、多标签页、自动化测试、日志记录等），现有 UI 逐渐暴露出体验瓶颈：

1. **欢迎页过于简陋**：只有文本提示，缺少快捷入口。
2. **高频操作依赖菜单**：新建连接、保存、显示日志等操作路径过深。
3. **缺少“编辑”菜单**：变量与测试步骤只能通过面板按钮操作。
4. **原生 `wxAuiNotebook` 与整体风格不搭**：标签栏自带厚重边框，和卡片式界面冲突。
5. **`wxEVT_UPDATE_UI` 轮询开销大**：工具栏图标在空闲时被反复重绘，造成卡顿。

## 决策

对 `MainFrame`、`SessionPanel` 与各对话框做“工作台（Workbench）”风格重构。

### 1. 自绘工作台骨架

- 自绘标题栏：拖拽移动、最小化 / 最大化 / 关闭。
- 顶部 `File` / `编辑` 两个下拉菜单，右侧提供日志、语言、设置、关于四个图标。
- 底部状态栏显示连接状态与收发字节数。

### 2. 自定义标签栏 `TabBook`

- 由“自绘标签条 + `wxSimplebook`”组成，替代 `wxAuiNotebook`。
- 页面必须先 `Reparent` 到 `wxSimplebook`：`wxSimplebook` 不会自动认领页面，否则页面会以 `TabBook` 为坐标原点覆盖标签栏，并被 simplebook 挡住导致整页收不到鼠标事件。
- 标签标题刷新只更新文字（`TabItem::SetTitle`），不得 `DestroyChildren()` 重建，否则关闭按钮的点击绑定会丢失。
- 标签可关闭；欢迎页同样可关闭；当只剩一个页面时自动隐藏关闭按钮。
- 文字与关闭按钮的背景色跟随标签激活状态，避免出现白块。

### 3. 会话内工具栏（不是全局 `wxToolBar`）

- 工具栏放在每个 `SessionPanel` 顶部，使用原生 `wxBitmapButton`，保证命中、焦点、禁用态由系统负责。
- 按钮点击直接绑定 `wxEVT_BUTTON`，不再依赖 `wxEVT_UPDATE_UI` 轮询。
- 新增 `UpdateToolbarState()`：在会话状态变化、列表选中/取消选中、页签切换、录制开关、流程开始/结束等明确时机刷新图标、ToolTip 与可用状态；按钮内部缓存“当前图标名”，只有真正变化才重新解码 SVG。
- 工具栏按上下文切换变量/步骤操作；运行与停止合并为一个按钮。

### 4. 编辑菜单

- `MainFrame` 的 `编辑` 菜单在**弹出时**读取当前激活的 `SessionPanel`，把添加/复制/编辑/删除转发给当前标签页。
- 不跨 Tab 操作；没有激活会话时相关项置灰。

### 5. 欢迎页

- 仿 VS Code 的“开始 / 最近打开”两栏布局。
- 支持“新建连接”“打开连接”和最近配置文件直达。
- 作为普通标签页存在，可以关闭；全部会话关闭后会重新创建。

### 6. 对话框层级

- 所有自绘对话框统一使用 `wxBORDER_NONE | wxRESIZE_BORDER`，由系统绘制细边框与投影，与日志窗口保持一致的悬浮层级。
- 内容仍使用 `CardPanel` + sizer，边框变化不影响布局。

## 替代方案

| 方案 | 为什么没选 |
|---|---|
| 继续使用 `wxAuiNotebook` | 标签外观无法与自绘标题栏、卡片布局统一，且自带边框难以去掉。 |
| 全局 `wxToolBar` 承载所有操作 | 工具栏状态需要跨 Tab 同步，容易误操作；会话级操作放到会话页内更自然。 |
| 继续用 `wxEVT_UPDATE_UI` 刷新按钮 | 空闲时被反复调用，重复解码 SVG、`SetBitmap`，造成明显卡顿。 |
| 关闭按钮由页面绘制/命中 | 页面会覆盖标签栏，命中区域不稳定；改为标签条内的独立控件并由 `TabBook` 统一管理。 |

## 后果

**好处**

- 界面更接近现代 IDE，标签栏、工具栏、欢迎页风格统一。
- 工具栏只在状态变化时刷新，空闲 CPU 占用和卡顿显著下降。
- 欢迎页可关闭、最后一页自动隐藏关闭按钮，交互更符合直觉。
- 所有对话框都有明确的边框与投影，不再和主窗口“糊”在一起。

**代价 / 约束**

- `TabBook` 的页面必须 `Reparent` 到 `wxSimplebook`；新增页面入口时不要绕过 `TabBook::AddPage/InsertPage`。
- 标签标题只能通过 `SetPageText()` / `TabItem::SetTitle()` 更新，禁止重建标签子控件。
- 工具栏按钮的可用状态必须由 `UpdateToolbarState()` 显式驱动；新增按钮时要在该函数和触发点中补齐。
- 对话框新增时必须带上 `wxRESIZE_BORDER`，否则会退回无边框、无阴影的状态。
- 新增/修改用户可见字符串后，需要重新执行 i18n 提取与编译（`.pot` → `.po` → `.mo`）。
