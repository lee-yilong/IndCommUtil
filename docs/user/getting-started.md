# 快速上手

## 1. 这是什么

**IndComm**（Industrial Communication Utility）是一个面向工业现场的多协议通讯测试/调试工具，
用来连 PLC、单片机、网关、串口设备，手动收发报文、观察原始数据。

定位类似 NetAssist + Modbus Poll + MQTT Explorer 的整合版。目前实现了 **TCP/IP** 协议、
**串口** 以及 **Modbus**（TCP / RTU / ASCII）。

---

## 2. 安装

可以下载 GitHub Releases 里的 `IndComm-Setup.exe`（NSIS 安装包）或免安装 `.zip`，也可以直接用构建产物：

```bash
# 见 docs/developer/building.md
scripts/build.sh
./build/IndComm.exe
```

运行时需要与 exe 同目录的 wxWidgets DLL 和 `resources/i18n/`（构建时已自动复制）。

## 3. 界面结构

启动后是**欢迎页**（“欢迎”标签），左侧是“Start”，右侧是“Recent”。窗口顶部是自绘工作台：

- **左侧菜单**：`File`、`编辑`；
- **右上角图标**：日志、语言、设置、关于；
- **中间标签栏**：每个连接一个标签，可以关闭、可以切换；
- **底部状态栏**：显示当前连接状态。

菜单项：

| 菜单 | 项 | 说明 |
|---|---|---|
| **File** | New | 打开新建连接向导（协议、模式、角色、参数） |
| | 最近连接 | 最近打开的 `.json`，最多 5 个 |
| | Open | 打开已保存的 `.json` |
| | Save / Save As | 保存当前配置 |
| | Close | 关闭当前连接 |
| | Quit | 退出 |
| **编辑** | 添加 / 复制 / 编辑 / 删除 | 作用于当前标签页的变量或测试步骤 |

右上角图标：

| 图标 | 功能 |
|---|---|
| 日志 | 打开日志窗口（可加载历史 `.log`） |
| 语言 | 切换简体中文 / English |
| 设置 | 打开应用程序设置 |
| 关于 | 查看版本信息 |

**建立连接后的主界面**采用左右分栏布局：

- **顶部工具栏**：当前会话的常用操作（打开/断开、配置、录制、历史、变量与步骤的增删改查、运行/停止、批量生成、上移/下移）。未选中变量或步骤时，相关按钮会自动置灰。
- **左侧**：固定的“通讯变量”列表。可以添加、编辑、删除变量，并实时看到最新值。双击变量可直接编辑，右键有快捷菜单，也可以拖动调整顺序。
- **右侧**：多模式操作区（手动、交互、自动、图表）。手动模式下选中变量，右侧会自动生成该变量的参数配置与发送/读写按钮；输入值会按变量类型校验，类型不匹配时发送按钮会置灰。
- **自动 / 交互模式**：步骤列表同样支持双击编辑、右键菜单和拖动排序。运行时若某一步断言失败，会暂停并询问“重试 / 跳过 / 结束”，而不是直接终止整个流程。运行过程中顶部进度条会显示完成进度，当前步骤会自动高亮并滚动到可见位置。
- **图表 / 历史查询**：可以通过 `1s / 5s / 10s / 1min` 等快捷时间段切换视图；历史查询选择时间段后会自动填充起止时间。
- **底部**：通信日志，时间戳格式为 `YYYY-MM-DD HH:MM:SS`。

窗口标题显示 `IndComm - 当前连接名`；配置有未保存修改时名称后带 `*`。

## 4. 第一个连接（TCP 客户端）

**准备一个测试服务端**（MSYS2 里 `pacman -S netcat`）：

```bash
nc -l -p 5020
```

**在工具里：**

1. `File → New`，在向导中选择 `TCP/IP`
2. 模式选 **Client**，填：
   - Remote Host：`127.0.0.1`
   - Remote Port：`5020`
   - Connect Timeout：默认 3000 ms 即可
3. 确定 → 状态依次显示「连接中…」→「已连接」
4. 在左侧面板点击 **Add**，添加一个变量（如命名为 `my_data`）。
5. 选中该变量，在右侧面板的 `Value:` 输入框中输入 `hello`。
6. 点击 **Send** 按钮 → `nc` 终端会显示 `hello`。
7. 在 `nc` 里输入 `world` 回车 → 工具的接收区出现 `< world`，同时左侧变量的 `Value` 也会自动更新为 `world`。

**几个常用行为**

- 点「断开连接」再点「打开连接」是**直接重连**，不会重新弹配置对话框。
- 「配置连接…」只在**未连接**状态下可用，避免连上后改配置造成混乱。
- 勾了「自动重连」后，对端挂掉会自动重试，状态显示「重连中…」。

---

## 5. 做 TCP 服务器

1. `File → New`，选择 **TCP/IP**，模式选 **Server**
2. Listen Host `0.0.0.0`，Listen Port `5030`
3. 客户端连上来：

```bash
nc 127.0.0.1 5030
```

4. 面板上会显示客户端数量与编号（`#1`、`#2`…），收到的数据带客户端号前缀。
5. 选中左侧变量后点击发送，内容会**广播**给所有已连接客户端。

## 6. 保存与复用配置

- 保存后得到 `.json` 文件，可用文本编辑器查看：

```json
{
  "connection": {
    "protocol": "tcp",
    "mode": "Client",
    "remoteHost": "127.0.0.1",
    "remotePort": 5020
  }
}
```

- `File → Open` 或从「最近连接」里选，即可恢复配置并连接。
- `.json` 是纯文本，方便版本管理、批量生成、脚本化。

---

## 7. 语言与日志

- 点击右上角“语言”图标，选择 `简体中文` / `English`，确认后重启生效。
- 点击右上角“日志”图标打开日志窗口，可勾选自动滚动或加载历史 `.log` 文件。
- 日志文件位于可执行文件同目录的 `logs/app.log`。
